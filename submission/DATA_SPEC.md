# 데이터 활용 명세

## 필수 제주 데이터 1종

**제주특별자치도 주제3 상권분석을 위한 유동인구에 따른 카드 매출액 변화 데이터 활용 매쉬업결과**를 사용합니다. 제주데이터허브 데이터748, 공공데이터포털 식별자15074768입니다. 데이터포털 설명에도 제주빅데이터센터 데이터 활용과 제주데이터허브 출처가 명시돼 있습니다.

- [제주데이터허브 연계 메타데이터](https://data.edmgr.kr/dataView.do?id=jejudatahub-net-748), [원 포털 링크](https://www.jejudatahub.net/data/view/data/748), [공공데이터포털 명세](https://www.data.go.kr/data/15074768/fileData.do).
- 2026-11-18 확인: 공공데이터포털은 **이용허락범위 제한 없음**, 연계 메타데이터는 **cc-zero**로 표기합니다. 이용 시 최신 원 제공처 조건을 함께 확인하고 이 출처를 유지합니다.
- 시연 추출 항목: 2021-04/05, **제주시 애월읍 / 한식 음식점업 / 카드 이용금액**. 금액은 **2,049,456,994 → 2,199,885,864원(+7.34%)**입니다. 유동인구를 실제 매장 방문자 수로 해석하지 않습니다.
- 실행 데이터 위치: `backend/src/main/resources/jeju-market-data.json`의 `cardAmounts`. 지역명→업종명→YYYY-MM→원 단위 금액으로 정규화한 실행용 집계 JSON입니다. 메타데이터가 열리는 것과 원본 CSV 파일을 이번에 다시 내려받아 대조한 것은 구분합니다. 이번 묶음에는 실행용 집계가 포함되며 원 제공처 CSV 전체를 새로 확보했다고 주장하지 않습니다.
- 처리 흐름: 월·지역·업종 정규화 → 두 달 동일 조건 금액 조회 → `(후-전)/전×100` 계산 → 매장 POS 변화와 나란히 표시 → 서버가 사실·출처를 AI 요청에 연결 → 사장님이 점검할 대응 선택. 매장 POS 감소를 상권 증가로 덮어쓰거나 카드 이용액을 실제 식당 매출이라고 표시하지 않습니다.
- 사용 코드: `JejuMarketContext.java`, `SalesStrategies.java`, `ChartQuestionEvidence.java`, `frontend/src/data/marketSources.ts`. 실제 저장 분석의 지역·업종·기간에 맞춰 연결합니다. 자료가 없으면 비교 없음/범위가 다른 참고 자료로 표시합니다.

POS 전처리는 결제 상태·날짜·주문 ID·수량·금액을 검사하고 결제와 상품 주문 합계를 대조합니다. 월 전체 여부·영업일 자료 범위는 사용자가 확인하며 누락일을 자동으로 휴무라고 단정하지 않습니다. 실행 전후는 5/18~31과6/1~14 각12영업일로 비교합니다. 개인 고객·실제 카드번호·실제 거래내역은 제공하지 않습니다.

상권 스냅샷은 정적 자료이며 자동으로 매달 최신 데이터가 되는 구조가 아닙니다. 새 기간 자료 확보·이용조건 확인·전처리·일치 검증을 거쳐 갱신해야 합니다. 후기·기상청·지도·AI API는 외부 의존성이며 오프라인에서 성공한다고 보장하지 않습니다.
