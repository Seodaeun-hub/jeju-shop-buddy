## 심사위원 실행 방법

**미리 정해진 서비스 계정 비밀번호는 제공하지 않습니다.** ZIP의 `02_문서/심사위원_실행안내.md` 순서대로 별도 빈 DB와 로컬 서비스를 준비한 뒤 **새 평가 계정 회원가입 → 매장 등록 → 제공된 CSV 4개 입력**으로 시작합니다. GitHub에서 소스를 받은 경우에는 [실행 매뉴얼](RUNBOOK.md)을 따릅니다. 공개 QR 메뉴판은 로그인 없이 열 수 있습니다.

최종 ZIP을 별도 폴더에 풀고 새 Python 가상환경·독립 DB를 구성해 설치·빌드, 회원가입·매장 등록·CSV 입력, 실제 AI 질문·후기 검색·홍보 생성·음성 전사를 확인했습니다. 같은 PC에서 분리된 실행환경을 사용한 검증이며, 센터 PC나 새 운영체제에서의 검증을 뜻하지 않습니다.

## 평가용 키와 공개 소스의 구분

- 실제 평가용 외부 AI API 키는 대회 규칙의 허용 범위에 따라 **심사위원용 ZIP의 `02_문서/평가전용/openai-api-key.txt`에만** 포함했습니다. GitHub·기획서·공개 촬영 자료에는 키 값을 넣지 않았습니다.
- 평가용 키 만료일은 **2026-11-30**, 프로젝트 월 예산 설정은 **US$10**입니다. 예산 설정은 요청을 강제로 중단하는 한도를 보장하지 않으며, 평가 기간 동안 사용량을 확인하고 평가 종료 후 키를 폐기합니다.
- 네이버·기상청·토스 등 다른 서비스 인증정보는 포함하지 않습니다. 필요한 기능은 실행 안내의 발급·설정 절차를 따릅니다.
- 실제 운영 DB·세션·서비스 비밀번호·`.env`·`.git`·가상환경·개발 캐시는 제출 소스에 포함하지 않습니다.

## 최종 파일 확인 범위

기획서는 제출 전 업로드된 PDF와 로컬 최종 PDF의 바이트 일치를 확인했고, 제출 후 같은 PDF 객체 링크와 15페이지 표시를 확인했습니다. ZIP은 **업로드된 파일명과 업로드 완료 표시**, 로컬 최종본의 CRC·manifest·SHA-256을 확인했습니다. 업로드된 ZIP을 다시 내려받아 로컬 파일과 바이트 단위로 비교한 것은 아닙니다. 유튜브 링크·미리보기 확인은 전체 영상의 화질 검토를 뜻하지 않습니다.

제출 소스 기준은 `main`의 `5a769487eab223b3e186d484f8919915c17cb999`입니다. 이번 README 정리는 제출 후의 문서 정리이며, 이미 업로드한 PDF·ZIP을 수정하거나 재제출하지 않습니다.

## 개발용 패키지 재생성

저장소 루트에서 `python submission/build_package.py --output 새_출력폴더`를 실행하면 공개 소스와 촬영 자료의 **키 없는 개발용 패키지**를 만듭니다. 기본 사진·프롬프트·QR·캡처는 `submission/assets/`를 사용하며, 필요한 경우 `--menu-assets 사진폴더 --verified-assets QR과캡처폴더`로 다른 자료를 지정합니다. 기존 출력 폴더는 덮어쓰지 않습니다.

이 스크립트는 비공개 최종 PDF·평가용 키를 자동으로 수집하지 않으며, 제출한 심사위원용 ZIP을 그대로 재현하는 명령이 아닙니다. 생성 후에는 실제 포함 자료·manifest·민감정보 제외 여부를 별도로 확인합니다.
