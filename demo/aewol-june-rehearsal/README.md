# 2021년 6월 애월 운영 의사결정 시연

2021년 4·5월 제주데이터허브의 애월읍 한식 음식점업 카드 이용액과 가상 매장 POS를 비교한다. 6월 대응은 같은 매장의 주문 안내 점검, 발주 검토, 지역 행사 홍보 초안, 다국어 QR 메뉴판으로 이어진다.

## 시연 자료

- [4월 결제](2021-04-payment.csv)와 [4월 상품 주문](2021-04-product.csv)
- [5월 결제](2021-05-payment.csv)와 [5월 상품 주문](2021-05-product.csv)
- [고기국수 예시 사진](../../frontend/src/assets/gogi-guksu.jpg)

CSV는 가상 POS의 결제와 상품 주문 시트를 월별로 내보낸 파일이다. 주문 식별자와 결제수단을 제외하고 결제 상태·시각·금액, 메뉴·수량·가격을 보존했다. 매장 분석은 완료 건을 집계한다.

## 시연 순서

로그인한 뒤 화면 상단에서 **시연 기준일 설정 → 애월 시연 · 2021년 6월 1일 → 시연 날짜 적용**을 누릅니다. 상단에 **시연 기준일 · 2021.06.01**이 보이는지 확인합니다. PC 날짜는 바꾸지 않습니다. 아이폰도 같은 계정으로 로그인하고 새로고침하면 적용됩니다. 시연 종료 후 **날짜 변경 → 실제 날짜로 돌아가기**로 해제할 수 있습니다.

1. **내 매장 → 매장 등록**에서 **애월 가상 한식당**, **제주시 애월읍**, **한식 음식점업**을 선택한다. 기상청 관측소 매칭을 위한 시연용 주소는 **제주특별자치도 제주시 애월읍 애월해안로 7**을 입력한다.
2. **POS 파일 관리**에서 CSV 네 개를 종류별로 저장한다. 기간은 4월 1~30일과 5월 1~31일이다. **매출 입력 → 내 매장 월별 파일**에서 기준 월 **2021-04**, 비교 월 **2021-05**를 지정한다.

   **분석 이름**은 **애월 2021년 6월 대응 시연**으로 입력한다. **요즘 어떤 점이 고민인가요?**에는 아래 문구를 입력한다.

   > 4월보다 5월 매출이 줄었어요. 주변 한식 음식점 상권과 비교해 우리 가게 상황을 알고 싶어요.
   > 어떤 메뉴와 시간대에서 매출이 많이 줄었는지 확인하고 싶어요.
   > 그 근거를 바탕으로 6월에 무엇부터 바꾸면 좋을지 추천받고, 발주량과 홍보 방법도 정하고 싶어요.

   메뉴 이름과 감소 수치를 미리 적지 않고 저장된 POS에서 AI가 근거를 찾도록 한다. 입력을 마치면 **이 자료로 분석하기**를 누른다.
3. **매출 분석**에서 **32,379,500원 → 29,581,000원(−8.64%)**, 애월 한식 카드 이용액 **+7.34%**, 오후 2~5시 결제 **337 → 189건**을 확인한다. **대응 전략 보기 → 주문 안내 점검하기 → 근거와 출처 보기**에서 제주데이터허브 근거를 확인하고 **선택하기**에서 계획 시작일 **2021-06-01**을 지정한다. 주문 가능 시간과 매장 안내의 일치 여부를 먼저 점검한다.
4. 먼저 **내 매장 → 메뉴 재료·원가 → 고기국수**에서 시연용 재료 **돼지고기**, 단위 **kg**, 한 개당 사용량 **0.5**, kg당 단가 **10,600원**을 입력하고 **재료·원가 저장**을 누른다. 이 값은 실제 식당 원가가 아닌 계산 확인용 예시이며 합산 원가는 **5,300원**이다. 같은 분석의 **발주량 검토** 전략을 선택하고 시작일 **2021-06-01**로 계획을 만든다. **날씨를 확인할 날짜 2021-06-05 → 고기국수 → 예상 판매량 보기** 순서로 진행한다. 기상청 제주 관측소의 과거 관측과 비가 기록되지 않은 토요일 POS 6일을 대조하면 **13~28그릇**이 나온다. 저장한 돼지고기 사용량이 자동으로 표시되며 **현재 재고 3kg·입고 예정량 1kg**만 입력하면 예상 사용량 **6.5~14kg**, 추가 준비량 **2.5~10kg**이 나온다. **발주 검토표 저장**으로 기록한다. 사용량 변경은 **내 매장에서 사용량 수정**에서 저장한 뒤 **저장한 사용량으로 발주 검토하기**로 돌아온다. 6월 5일 관측은 당시 조건을 적용하는 과거 시나리오에 사용한다.
5. 같은 분석의 **홍보** 계획에서 시작일 **2021-06-01**, 기간 **2주**를 정한다. 고기국수 판매가 **8,500원**, 시연 원가 **5,300원**, 할인 **1,000원**, 예산 **30,000원**으로 검토하면 **7,500원·30개 한정·6월 1~14일** 조건이 나온다. **홍보물 만들기**에서 게시 희망일 **2021-06-05**와 **제주현대미술관 《공(空)의 매혹》 전시**를 선택해 저장한다. **홍보물 보기**의 인스타그램·네이버 플레이스·당근 탭에서 같은 기간·가격·수량과 출처를 확인한다.
6. **내 매장 → 메뉴 사진 관리**에서 고기국수 예시 사진을 올린다. **다국어 QR 메뉴판**에서 저장한 메뉴 10개와 POS 가격을 확인하고 **영어·중국어·일본어 초안 만들기**를 누른다. 번역과 사진을 확인하고 **메뉴판 공개**를 누른 뒤, 관리 화면의 QR을 아이폰에서 열어 네 언어를 확인한다. AI 서비스를 호출할 수 없는 환경에서는 아래 번역 예시를 직접 입력한다.

고기국수는 월 전체 판매량이 **495 → 505그릇**이고, 오후 2~5시 주문 시작 기준은 **156 → 110그릇**이다. 오후 시간대에 다시 안내할 메뉴로 선택한다. 질문 예시는 “매출이 가장 많이 줄어든 메뉴와 결제가 가장 많이 줄어든 시간대를 알려줘”이다. 메뉴 매출 기준 답은 **김치찌개 4,965,000원 → 4,221,000원**이다.

## 데이터 출처와 검증 범위

- 상권 비교에는 제주데이터허브의 2021년 4·5월 읍·면·동과 업종별 카드 이용액을 사용한다. [제주데이터허브 자료](https://data.edmgr.kr/dataView.do?id=jejudatahub-net-748) · [공공데이터포털 명세](https://www.data.go.kr/data/15074768/fileData.do)
- 과거 날씨는 기상청 종관기상관측(ASOS)의 제주 관측소 일별 자료로 비교한다. [기상청 과거관측](https://www.weather.go.kr/w/weather/land/past-obs/obs-by-day.do?stn=184&yy=2021&mm=6&obs=9)
- 전시 기간은 2021년 3월 23일~6월 27일이다. [참여 작가 전시 기록](https://ganaatelier.com/152) · [제주특별자치도의회 전시 현황](https://record.council.jeju.kr/CLRecords/Files/FileAppendix/a12/A038490.pdf)
- 시연 범위는 근거를 반영한 계획 저장, 발주 검토, 홍보 초안과 시연용 QR 공개까지다. 매출 효과 검증에는 실행 후 실제 POS가 필요하다.

## 로컬 리허설 결과

- 격리된 PostgreSQL과 Chrome에서 CSV 4개를 보관한 뒤 집계했다. 매출 32,379,500원 → 29,581,000원, 오후 2~5시 결제 337 → 189건, 메뉴 10개와 상권 카드 이용액 +7.34%를 확인했다.
- 로컬 기본 추천에서 제주데이터허브 근거를 확인하고, 6월 1일을 준비일로 저장했다. 주문 안내 점검의 관찰 기간은 6월 3~16일로 표시됐고 새로고침 후 유지됐다.
- 기상청 실제 관측이 반영된 6월 5일 고기국수 예상 판매량은 13~28그릇, 추가 준비량은 2.5~10kg이었다.
- 390px 너비 Chrome에서 세 채널의 전시·고기국수 문구, 7,500원·30개 한정·6월 1~14일 조건을 확인했다. 확인한 초안은 로컬 기본 생성 결과다.
- 같은 Chrome 크기의 별도 비로그인 창에서 공개 메뉴 10개와 네 언어 전환을 확인했다. 고기국수의 8,500원과 사진이 로드됐다. 리허설에서 번역은 아래 예시를 직접 입력했다.
