# 가게짝꿍

제주 상권 데이터와 매장 POS를 함께 분석하고, 발주·홍보 준비와 실행 결과 확인까지 돕는 AI Agent 웹 서비스입니다.

[서비스 열기](https://gage-jjakkung.up.railway.app/) · [시연 영상](https://www.youtube.com/watch?v=CKIk7-hy9lM) · [설치·실행 안내](submission/RUNBOOK.md)

## 주요 기능

| 기능 | 할 수 있는 일 |
|---|---|
| 매출·상권 분석 | 월별 POS를 입력하고 같은 기간·지역·업종의 카드 이용액과 비교합니다. |
| 근거를 보여주는 AI 질문 | 메뉴·시간대별 변화를 질문하고 계산에 사용한 자료를 확인합니다. 음성으로 입력한 질문은 사용자가 보내기를 눌러 전송합니다. |
| 하루 발주 검토 | 같은 요일 판매 기록·최근 추세·날씨 자료를 참고하고, 재료 사용량·재고·기존 입고량으로 추가 준비량을 검토합니다. |
| 세 채널 홍보 | 공개 후기와 제주 행사 정보를 참고해 인스타그램·네이버 플레이스·당근 초안을 만듭니다. 게시 전 확인과 실제 게시는 사용자가 진행합니다. |
| 다국어 QR 메뉴판 | 메뉴 사진과 정보를 한국어·영어·중국어·일본어로 제공합니다. |
| 실행 결과 확인 | 홍보 전후 POS와 발주 예상·실제 판매·남은 재고를 기록하고 전체 흐름을 살펴봅니다. |

## 시연 자료

본편은 **2021년 4·5월 애월읍 매출 분석 → 6월 대응 → 실행 결과 확인** 순서입니다. 일반 사용은 현재 날짜를 기준으로 하며, 과거 시연은 앱의 시연 기준일을 별도로 설정합니다.

- **실제 자료:** 제주데이터허브의 애월읍 한식 음식점업 카드 이용액, 출처를 확인한 공개 후기·기상 관측 등입니다.
- **가상 자료:** 더애월 공개정보를 참고한 매장 POS·재고·재료 원가·실행 결과와 AI 예시 음식 사진입니다. 실제 매장 매출이나 개선 성과를 뜻하지 않습니다.

시연에서 매장 매출은 약 **1,634만 → 1,451만 원(−11.23%)**, 같은 기간 상권 카드 이용액은 **+7.34%**입니다. 김치찌개 판매량과 오후 시간대 결제 감소를 확인한 뒤 발주 검토·홍보로 이어집니다.

입력할 CSV·사진·가격·재료표와 순서는 [더애월 시연 안내](demo/the-aewol-june-rehearsal/README.md), PC·아이폰 촬영과 설명 멘트는 [촬영 README](demo/final-recording/README.md)에 정리했습니다.

## 로컬 실행

프런트엔드는 React·TypeScript·Vite, 백엔드는 Spring Boot·Java 21, Agent는 Python·FastAPI·LangGraph로 구성하며 PostgreSQL을 사용합니다. 외부 OpenAI API를 호출하므로 인터넷과 API 설정이 필요합니다.

1. Java 21, Maven 3.9 이상, Node.js 22 이상, Python 3.11 이상, PostgreSQL을 준비합니다.
2. 별도의 빈 DB에 스키마와 마이그레이션을 적용합니다.
3. 환경변수를 설정한 뒤 Agent → 백엔드 → 프런트엔드를 실행합니다.
4. 새 계정·매장을 만들고 시연 CSV를 입력합니다.

명령어·환경변수·외부 API 발급처·오류 대응은 [실행 매뉴얼](submission/RUNBOOK.md)을 따릅니다. Railway 설정은 [배포 안내](deploy/railway.md)를 확인합니다.
